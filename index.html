Balancing Global Planning and Local Rendering for Long Multi-Shot Video Generation

Coherence across Time, for movies longer than any generation window.

Jinpeng Lu* · Haoyuan Shi* · Yuanshen Guan · Jiyuan Xia · Bin Wu · Yinda Chen · Zhiwei Xiong

Diffusion transformers generate only a few seconds per pass, so minute-long stories must be stitched from local windows where either identity drifts or camera cuts fail. CaT-Movie connects a training-free global story planner with a local window renderer through one structured storyboard that decouples persistent identity from per-shot state and framing.

The trade-off

Existing generators either execute camera cuts or preserve identity across them.

Per-shot pipelines cut cleanly but rebuild the cast in every shot. Joint multi-shot generators coordinate cuts inside a window but lose identity at window seams. Memory-augmented generators carry raw frames forward, bundling identity with prior camera framing so planned cuts repeat old setups.

Method

One structured storyboard decouples identity from per-shot state and framing.

Given a story request at any granularity, a training-free global story planner writes an entity registry and per-shot plans. Deterministic code maintains cross-shot state, compiles self-contained shot prompts, and routes anchor views into a local window renderer that denoises each window jointly.

01 · Request

Three input granularities, one contract.

A unified prompt guides frozen Qwen3.8-27B to expand a one-sentence synopsis, paragraph, or numbered shot list into valid storyboard JSON: preserve stated facts, infer implied presence and outcomes, and complete open visual details.

Retains 100% of requested events and 90–98% of outcomes across 70 stories.
02 · Storyboard

Entity registry & state propagation.

The storyboard links a global entity registry (fixed IDs, appearance, default attire) with per-shot plans. Deterministic code propagates attire changes and held items across shots to compile one self-contained prompt per shot.

Code state propagation lifts post-change attire accuracy by +14.1 pts.
03 · Windows

Duration scaling & greedy packing.

Predicted shot durations are scaled to the target video length and greedily packed into multi-shot windows under a 7 s cap. Shots inside each window are denoised jointly to coordinate local camera cuts directly.

91.4% of entity returns in test storyboards cross a window boundary.
04 · Recall

Storyboard-indexed anchor views.

Rather than taking the latest shot (which chains errors across windows), code queries the storyboard for each entity's clearest anchor view after its latest state change, routing each recalled frame only to shots where that entity appears.

Anchor views beat recent-shot recall by +9.3 pts on Character and +15.4 pts at ≥2 windows apart.
05 · Render

Routed window attention.

Each shot is VAE-encoded separately so no latent straddles a cut. Under shot-wise cross-attention and reference-routed sparse self-attention, each shot reads its own tokens, co-generated first frames, and its routed anchor views.

Entity routing lifts cut execution from 0.869 to 0.970 when hiding absent-character frames.

Consistency counts only when the planned cut is executed.

Feature-similarity metrics such as ViCLIP and DINOv2 reward videos that repeat the previous camera framing across a planned cut. CaT-MBench pairs entity-specific binary checks with an explicit cut gate: a returning character, object, or scene is credited as consistent only if TransNetV2 and the VLM judge verify that the planned cut opened a new camera setup.

Finding 1 · Cross-Window Drift

Joint generators reset identity at window seams.

28% / 30% character pass rate across windows

HoloCine and MultiShotMaster pass 62–83% of character checks within a single window, but drop to 28% and 30% as soon as a character crosses a window boundary.

Finding 2 · Copied Framing

Raw frame memory copies prior camera setups.

114of 674 planned setup changes repeated by StoryMem

StoryMem fails the cut gate on 15.7% of consistency checks (vs. 0.7% for CaT-Movie). Omitting the cut gate inflates its consistency score by over 15.3 points.

Finding 3 · Per-Shot Amnesia

Independent per-shot pipelines cut cleanly but forget.

0.17–0.30character consistency across per-shot baselines

Per-shot Wan2.1/2.2 and keyframe pipelines (StoryDiffusion, IC-LoRA) execute over 90% of cuts, but independent sampling collapses cross-shot identity.

Ablation studies

30 development stories over three seeds. Toggle to view point differences from CaT-Movie († marks 95% bootstrap intervals excluding zero).

Ablation 1 · Renderer & Attention

Routing prevents framing copy.

Dropping references collapses Character (−29.2 pts) and Object (−24.3 pts). Removing entity routing drops cut execution from 0.970 to 0.869 on cuts where routing hides absent-character frames.

Ablation 2 · Reference Recall

Anchor views beat recent & CLIP recall.

Recalling from recent shots degrades Execution (−3.0 pts), Character (−9.3 pts), and Scene (−9.5 pts) due to error chaining across windows. CLIP retrieval drops the overall average by 3.4 pts.

Ablation 3 · Storyboard Source

Planner state tracking lifts rendering.

Our planner's storyboard beats directly compiled requests across every column (+5.4 Character, +16.0 Establish, +15.1 Persist) and surpasses the reference storyboard by +9.3 pts on Persist.

Film storyboard dataset

358K film shots annotated in the exact schema the planner writes.
